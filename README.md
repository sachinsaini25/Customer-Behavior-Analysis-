# 🛍️ Customer Shopping Behavior Analysis

## 📊 Project Overview

This project analyzes **customer shopping behavior** using transactional data containing **3,900 purchases across different product categories**. The objective is to identify customer spending patterns, product preferences, customer segments, subscription behavior, and revenue trends to support better business decisions.

The project combines:

* 🐍 **Python** – Data Cleaning & Exploratory Data Analysis
* 🗄️ **PostgreSQL / SQL** – Business & Customer Analysis
* 📊 **Power BI** – Interactive Dashboard & Visualization

---

## 📁 Dataset

The dataset contains:

* **3,900 rows**
* **18 columns**
* Customer demographic information
* Purchase information
* Shopping behavior
* Subscription status
* Shipping information
* Review ratings

### Key Dataset Features

| Category              | Features                                                       |
| --------------------- | -------------------------------------------------------------- |
| Customer Demographics | Age, Gender, Location, Subscription Status                     |
| Purchase Details      | Item Purchased, Category, Purchase Amount, Season, Size, Color |
| Shopping Behavior     | Discount Applied, Previous Purchases, Frequency of Purchases   |
| Customer Feedback     | Review Rating                                                  |
| Delivery              | Shipping Type                                                  |

The original dataset contained **37 missing values in the Review Rating column**.

# 🐍 1. Data Analysis Using Python

Python was used for preparing and cleaning the dataset before performing SQL analysis.

### Data Preparation

The following steps were performed:

* Loaded the dataset using **Pandas**
* Inspected the dataset using `df.info()`
* Generated statistical summaries using `df.describe()`
* Checked for missing values
* Handled missing review ratings
* Standardized column names using **snake_case**
* Created an **age_group** feature
* Created a **purchase_frequency_days** feature
* Checked redundant columns
* Removed `promo_code_used`
* Connected the cleaned DataFrame to PostgreSQL

Missing review ratings were imputed using the **median rating of each product category**.

---

# 🗄️ 2. SQL Analysis Using PostgreSQL

PostgreSQL was used to answer important business questions from the cleaned customer transaction data.

### Business Questions

1. **Revenue by Gender**

   * Compared revenue generated by male and female customers.

2. **High-Spending Discount Users**

   * Identified customers who used discounts but still spent above the average purchase amount.

3. **Top 5 Products by Rating**

   * Identified products with the highest average review ratings.

4. **Shipping Type Comparison**

   * Compared average purchase amounts between Standard and Express shipping.

5. **Subscribers vs Non-Subscribers**

   * Compared average spending and total revenue between subscribers and non-subscribers.

6. **Discount-Dependent Products**

   * Identified products with the highest percentage of discounted purchases.

7. **Customer Segmentation**

   * Classified customers into:

     * New
     * Returning
     * Loyal

8. **Top 3 Products per Category**

   * Identified the most purchased products within each category.

9. **Repeat Buyers & Subscriptions**

   * Analyzed whether customers with more than five purchases were more likely to subscribe.

10. **Revenue by Age Group**

    * Calculated revenue contribution from different age groups.

# 💡 Business Recommendations

Based on the analysis, the following recommendations were identified:

### 1. 🚀 Boost Subscriptions

Promote exclusive benefits and offers for subscribers to increase subscription adoption.

### 2. 🎁 Customer Loyalty Programs

Reward repeat customers and encourage them to move into the **Loyal Customer** segment.

### 3. 💸 Review Discount Policy

Evaluate discount strategies to increase sales while maintaining healthy profit margins.

### 4. ⭐ Product Positioning

Promote top-rated and best-selling products through targeted marketing campaigns.

### 5. 🎯 Targeted Marketing

Focus marketing efforts on high-revenue age groups and customers using express shipping.
